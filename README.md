🏥 Healthcare Data Analysis using SQL
📌 Project Overview

This project focuses on analyzing healthcare data using SQL to extract meaningful insights and answer real-world, business-oriented questions. The analysis helps understand patient distribution, departmental performance, and expense trends using structured query techniques.

The project demonstrates strong fundamentals in SQL querying, data analysis, and analytical thinking.

🗂️ Dataset Information

Source: Healthcare/Hospital dataset

Format: CSV

Data Includes:

Patient details

Department information

Admission and discharge dates

Expenses and related metrics

🛠️ Tools & Technologies Used

SQL

MySQL / SQL Server

CSV Dataset

GitHub

🔍 Key SQL Concepts Used

SELECT, WHERE

GROUP BY, HAVING

Aggregate functions (COUNT, SUM, AVG)

Date functions

Sorting and filtering

Business-driven query logic

📊 Key Insights Derived

Analyzed patient counts across departments

Calculated average values for key healthcare metrics

Evaluated department-wise performance

Identified expense trends over time

Answered real-world healthcare business questions using SQL
